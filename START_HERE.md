## ⚡ 30-Second Quick Start

```powershell
# 1. Install dependencies (30 sec)
npm install

# 2. Set up MongoDB (2 min) - go to mongodb.com/cloud/atlas
# 3. Add MongoDB URI to .env.local (1 min)
# 4. Run the app (1 min)
npm run dev

# Now visit http://localhost:3000 ✨
```

### Step 1: Review Project (2 min)
Read [GETTING_STARTED.md](GETTING_STARTED.md) for overview

### Step 2: Set Up MongoDB (2 min)
- Go to mongodb.com/cloud/atlas
- Create free account
- Create free M0 cluster
- Get connection string

### Step 3: Configure Project (1 min)
- Edit `.env.local`
- Add MongoDB connection string

### Step 4: Run Locally (1 min)

Visit http://localhost:3000

- Update `.env.local`

### During Development

- Use `npm run dev` for development
- Use `npm run build` to test production build

### Before Deployment
- Read [DEPLOYMENT.md](DEPLOYMENT.md)
- Set `MONGODB_URI` in Vercel
